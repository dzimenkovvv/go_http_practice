# go_http_practice

Учебный проект для практики работы с HTTP-сервером на Go

Проект содержит простые примеры обработки HTTP-запросов с использованием стандартного пакета `net/http`, а также работу с конкурентным доступом к данным

## Содержит

### 1. Базовый HTTP сервер (simple_http_requests)
- Запуск HTTP-сервера
- Регистрация обработчиков (`http.HandleFunc`)
- Работа с `http.ResponseWriter` и `http.Request`
- Несколько эндпоинтов:
  - `/default`
  - `/pay`
  - `/cancel`

### 2. HTTP + конкурентный доступ (wallet_managment)
- Обработка POST-запросов с чтением тела запроса
- Простейшая логика "баланса" и "кошелька"
- Использование:
  - `sync.Mutex`
  - `sync/atomic`
- Потокобезопасное изменение общих данных
- Эндпоинты:
  - `/add` — пополнение баланса
  - `/pay` — списание средств
  - `/save` — перенос средств в кошелек
